## Setup
Semua kebutuhan project (Python app + Redis) diisolasi di `compose.yml`. One-time:

```bash
podman pull docker.io/library/python:3.12-slim docker.io/library/redis:7-alpine
```

`./testing` otomatis build image app (slim python + redis client) dan menyalakan redis. App pakai Redis beneran untuk distributed lock + idempotency store (`REDIS_URL=redis://redis:6379/0`); tanpa `REDIS_URL` (misal python lokal) otomatis fallback ke in-memory store.

## Run
Shortcut: satu command untuk semua test, via container compose:

```bash
./testing              # semua test (Part 2 + Part 3)
./testing checkout     # Part 2 saja: concurrency + handler demo (pakai Redis)
./testing triage       # Part 3 triage engine saja
./testing dispatch     # Part 3 dispatcher + reconciliation saja
./testing down         # matikan redis & app containers
```

Atau manual per script (container compose harus sudah jalan via `./testing checkout` dll):

```bash
podman compose -f compose.yml exec -T app python3 src/patch/test_concurrency.py
podman compose -f compose.yml exec -T app python3 src/engine/triage_engine.py
podman compose -f compose.yml exec -T app python3 src/engine/dispatcher.py
```

## What each part demonstrates
- **Part 1** (`docs/NETWORK_ARCHITECTURE.md`): Mermaid topology Kuta Hub -> HQ Renon -> Cloud, 802.1Q VLAN matrix (10/20/30/40/50) with DHCP scopes and QoS, dual-WAN health checks with < 3 s failover, and guest Wi-Fi throttle/drop to < 128 kbps on cellular backup.
- **Part 2** (`src/patch/`): TTL-based per-vehicle distributed lock (Redis-compatible interface, in-memory fallback), mandatory idempotency key deduplication, hold-confirmed-before-capture ordering, graceful 409 Conflict mapping. Test proves exactly 1 success + 4 conflicts + 1 payment capture out of 5 concurrent requests.
- **Part 3** (`src/engine/`): tags CRITICAL_SECURITY_ALERT (available car moving / restricted zone), OFFLINE_TELEMETRY_DROP (rented silent > 15 min), MAINTENANCE_REQUIRED (battery < 11.5V or fuel < 15%); dispatcher formats payloads, retries with exponential backoff + jitter, exports reconciliation JSON.
